# Outline (Jigsaw) — UX-логика и что перенять в HydraBox

Источники: `client/web/views/root_view/*`, `servers_view/*`, `client/web/app/app.ts`, `client/web/model/errors.ts`, `client/web/messages/en.json`, `docs/invitation_instructions.md` (репо Jigsaw-Code/outline-apps, master).

## 1. Контракт простоты
Домашний экран = карточка на сервер: имя, адрес, бейдж защиты, кнопка Connect/Disconnect. Всё. Ни выбора протокола, ни портов, ни шифров, ни логов. Единственное решение пользователя — какой сервер и «подключить». Продвинутое спрятано в меню «изменить/забыть», которое не видно, пока не нужно.

**Перенять:** для sing-box скрыть из дома весь словарь (tag, outbound, sniff, TUN, геосайты). Вместо протокола — бейдж-последствие: «Полная защита» / «Ограниченная защита» (у них `server-card-complete/limited-connection-type`), с диалогом «подробнее» по запросу. Это самое дешёвое и самое сильное: убирает 80% вопросов.

## 2. Явная машина состояний (топ по влиянию)
5 состояний + «недоступен», каждое — своя строка и своя анимация: `Connecting...`, `Connected`, `Reconnecting...`, `Disconnecting...`, `Disconnected`, `Unreachable`. `Reconnecting` — отдельное видимое состояние (`onServerReconnecting` → карточка), а не молчание. Смена статуса throttled (`DEFAULT_SERVER_CONNECTION_STATUS_CHANGE_TIMEOUT`), чтобы индикатор не мигал.

**Перенять:** sing-box имеет десяток внутренних фаз; в UI отдавать ровно эти 5–6 человеческих. Reconnect и «unreachable» показывать явно и отдельно от ошибок. Троттлинг переключений — обязательно, иначе sing-box-реконнекты дадут мигание.

## 3. Один маппер ошибок → человеческий текст + одно действие
`showLocalizedError()` — единственная точка: тип ошибки → фраза + опциональная кнопка + опциональная ссылка помощи. Тексты без вины и без жаргона, с одним следующим шагом:
- «We can't seem to connect to your server. Please check that you are connected to the internet and try again.»
- «It seems like your access key is not valid. If this happens again, please contact the person who gave it to you.»
- «It seems like another VPN is active. Please disconnect it and try again.»

**Перенять:** централизованный `error → {text, button, action}` для всех ошибок ядра (dial timeout, outbound unavailable, DNS, config parse). В тосте никогда не показывать сырой JSON sing-box. Каждая ошибка = ровно один предлагаемый шаг; для проблем вне клиента — «обратитесь к тому, кто дал конфиг».

## 4. «Details» + Copy вместо охоты за логами
Непрозрачный сбой → кнопка `Details` → диалог с сырым стеком (рекурсивно по `cause`), кнопкой `Copy`/`Copied` и инструкцией «сделайте скриншот и отошлите поставщику ключа». Плюс автоотчёт в Sentry с явной заметкой о приватности.

**Перенять:** интерактивная «поделиться логами» = текст + копирование в один клик, без поиска файлов на диске. Для HydraBox — копия последнего запуска ядра/ошибки.

## 5. Онбординг по ключу
Один инпут: «Paste access key here», monospace, живая валидация через `parseAccessKey`, кнопка Confirm заблокирована, пока ключ невалиден, инлайн-ошибка «Invalid access key». Ключ из буфера определяется сам → диалог «Access key detected. Please confirm…» (и есть «Ignore» с кэшем игноров, чтобы не приставать дважды). Первый запуск: ack приватности → автооткрытие диалога добавления. Zero-state — одна большая кнопка-индикатор + одна строка инструкции. Инструкция для приглашённого — 3 шага.

**Перенять:** вставить ссылку/конфиг → подтверждение, не «мастер из 5 шагов». Валидировать до включения. Не грузить настройками до первого подключения.

## 6. Мелкое, что держит предсказуемость
- Тосты подтверждают успех с именем: «Connected to “X”», «Added server “X”».
- «Forget» → тост с `Undo`; rename → подтверждение. Дёшево и снимает страх.
- Автоконнект объясняется диалогом «Stay protected, always» и запоминает отказ.
- Форма фидбэка с выбором типа вопроса и разводом «ключи бесплатно не выдаём / это к вашему провайдеру ключа».

**Перенять:** Undo для удаления профиля, тосты с именем профиля, объяснение автозапуска/автоконнекта вместо тихого поведения.

## Приоритет внедрения
1. 5–6 человеческих состояний + видимый reconnect/unreachable, троттлинг.
2. Один маппер ошибок: текст + одно действие, без жаргона.
3. Error-details с Copy («поделиться логами» в один клик).
4. Онбординг: вставка ключа с живой валидацией + автодетект из буфера.
5. Zero-state в один экран, настройки — после первого подключения.
6. Бейдж «полная/ограниченная защита» вместо технических терминов.
7. Undo/тосты с именами профилей.

Итог: причина — Outline прячет сложность и делает каждое состояние и каждую ошибку называемыми и однозначными; делать — перенести 5 состояний, один маппер ошибок и однострочный онбординг.
