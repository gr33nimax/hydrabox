# Changelog

## [0.2.2] - 2026-07-14

### VPN и раздельная маршрутизация

- Исправлена ситуация, когда VPN успешно подключался, но весь трафик уходил в таймаут. Служебные соединения ядра теперь надёжно исключаются из самого VPN-туннеля.
- Раздельная маршрутизация проверяет, какие приложения Android действительно добавил в VPN. Удалённый или некорректный пакет больше не оставляет подключение в частично применённом состоянии.
- На Android 8–12 добавлен запасной маршрут для выбранных приложений. Это устраняет случай, когда DNS работал, а сайты, видео и мессенджеры не получали TCP/UDP-трафик.
- Смена режима и списка приложений выполняет полный перезапуск VPN-сервиса. Несколько быстрых изменений объединяются, чтобы не запускать пересекающиеся остановки и подключения.
- Улучшено восстановление после смены Wi-Fi и мобильной сети, выключения экрана и возврата приложения из фона. Ручное отключение VPN больше не отменяется устаревшей командой восстановления.
- В диагностике указываются запрошенные и фактически применённые приложения, поэтому причину проблем с раздельной маршрутизацией проще определить по журналу.

### Серверы и проверка задержки

- Сервер, выбранный при выключенном VPN, сохраняется и используется при следующем подключении. После перезапуска приложения выбранный сервер также восстанавливается.
- Проверка задержки больше не выдаёт старое значение за результат новой проверки. При ошибке или таймауте клиент показывает реальное состояние сервера.
- Дополнительная проверка после подключения выполняет настоящий HTTP-запрос через группу серверов. Если в подписке больше 50 серверов, именно эта проверка пропускается, чтобы не создавать лишнюю нагрузку; проверка по расписанию и ручная проверка всех серверов остаются доступными.
- Группа «Самый быстрый» показывает задержку действительно выбранного сервера и больше не подставляет результат другого сервера. Для «Умной маршрутизации» не отображается вымышленное числовое значение.
- Команды выбора сервера и проверки задержки выполняются последовательно. Поздний ответ от старой команды больше не меняет текущий выбор и не запускает лишний перезапуск.
- Страна сервера больше не заменяется страной выходного IP, поэтому флаги не меняются после включения VPN или раздельной маршрутизации.
- Добавлены понятные названия для автоматического выбора сервера, умной маршрутизации и цепочек прокси.

### Подписки и защита данных

- Ошибки добавления и обновления подписок теперь объясняют причину: неверный адрес, пустой ответ, HTML вместо подписки, таймаут, ошибка DNS или TLS, отсутствие подходящих серверов и основные ответы HTTP 4xx/5xx.
- При активном VPN клиент старается обновлять подписки через физическую сеть устройства, чтобы запрос не зацикливался внутри туннеля.
- HWID, токены, Cookie и другие чувствительные заголовки разрешено отправлять только по HTTPS. При переходе на другой сайт такие заголовки удаляются, а перенаправление с HTTPS на HTTP блокируется.
- Настройки, содержимое подписок, пароли и ключи в локальном хранилище защищены шифрованием AES-GCM. Ключ хранится в Android Keystore, а старые данные переносятся автоматически.
- Секреты скрываются не только во Flutter-журнале, но и в нативной диагностике Android перед сохранением и экспортом.

### Интерфейс и производительность

- Запуск приложения больше не ждёт полной загрузки всех конфигураций подписок: сначала открывается интерфейс с краткими данными, а активная подписка загружается в фоне.
- Большой список серверов построен лениво и не создаёт все строки интерфейса одновременно. Кнопка «Ещё …» открывает оставшиеся серверы, а выбранная сортировка сохраняется после перезапуска.
- Обновление скорости, трафика и задержек изменяет только нужные элементы экрана вместо перестроения всего приложения каждую секунду.
- Нативная диагностика записывает сообщения пакетами в отдельном потоке, уменьшая количество операций с хранилищем при подробном журналировании.
- Добавлены Baseline и Startup Profile для ускорения запуска, открытия главного экрана и списка серверов на Android.
- Системные сообщения заменены едиными карточками внутри приложения с поддержкой подробного текста и кнопок действий.

### Android и обновление клиента

- Минимальная поддерживаемая версия повышена до Android 8.0 (API 26). Удалены устаревшие ветки для Android 5–7.
- Flutter обновлён до 3.44.6. Обновлена обработка системных разрешений VPN и установки APK.
- Установщик обновлений принимает APK только из закрытой папки Etonify и повторно проверяет файл перед передачей Android.
- Обычная CI-проверка и выпуск APK проверяют контрольную сумму встроенного `libbox.aar`, чтобы случайно изменённое ядро не попало в сборку.
- В CI добавлены сборка Android-клиента, модульные тесты, lint и проверка Android-кода через CodeQL.
- Версия приложения обновлена до `0.2.2+6`.

## [0.2.1] - 2026-07-05

### VPN и стабильность

- Исправлено зависание и исчерпание памяти при запуске раздельной маршрутизации с выбранными приложениями.
- Исправлены ложная потеря сетевого интерфейса, самопроизвольное восстановление VPN после ручной остановки и конфликтующие операции запуска, остановки и смены конфигурации.
- Улучшена обработка смены сети, восстановления после ошибок ядра и синхронизация состояния между Android-сервисом и интерфейсом.
- Добавлены отдельные режимы подключения: системный VPN TUN и локальный HTTP/SOCKS-прокси.
- Доступ к локальному прокси из LAN теперь защищён автоматически созданным логином и паролем.

### Проверка серверов и IP

- Проверки задержки объединены в одну управляемую сессию без параллельных повторов и частых фоновых запусков.
- Сохранён HTTP URLTest через прокси; ошибки EOF и таймауты больше не помечают работающий сервер как окончательно недоступный.
- Во время повторной проверки сохраняется последнее значение задержки, а состояние списка обновляется без зависшей анимации.
- Определение внешнего IP ускорено параллельным запросом к нескольким источникам с коротким таймаутом и кэшем.

### Подписки и интерфейс

- Переработан экран подписок: закреплённая шапка, плавное добавление профиля, сортировка и отдельное меню действий.
- Добавлены копирование URL и JSON, показ QR-кода, количество прокси и дата обновления.
- «Обновить все» выполняет ограниченное число запросов параллельно и показывает общий прогресс, не создавая дублирующиеся обновления.
- Исправлены рывки, лишние перестроения интерфейса и прокрутка пустого содержимого в нижних панелях.

### Маршрутизация и DNS

- «Маршруты России» переименованы в «Умную маршрутизацию».
- Добавлены проверка обновлений правил, встроенная офлайн-база и подробные этапы скачивания, проверки, распаковки и установки.
- Состояние обновления Умной маршрутизации и AdGuard DNS Filter сохраняется при переходе между экранами.
- Для AdGuard DNS Filter добавлены объём загрузки, ETA, сборка локального SRS и безопасная замена правил.
- Обычный адрес DNS, например `1.1.1.1`, принимается как UDP без подстановки `udp://` в поле ввода.
- Ускорены поиск приложений и загрузка иконок для раздельной маршрутизации; выбранное приложение можно удалить прямо из списка.

### Обновление клиента

- Updater учитывает ABI устройства и минимальную версию Android перед загрузкой APK.
- Перед установкой проверяются имя пакета, версия Android, сертификат подписи и SHA-256 из release manifest.
- Старые и уже установленные APK удаляются автоматически; этапы очистки, загрузки и проверки показываются в интерфейсе.
- GitHub Actions формирует universal и split-ABI APK, manifest обновления и черновик релиза с этим changelog.

### Прочее

- Обновлены экраны «О приложении», MeowTeam, пользовательское соглашение и политика конфиденциальности.
- Добавлены пояснения для `QUERY_ALL_PACKAGES`, HWID, установки APK и локального хранения диагностических данных.
- Версия приложения обновлена до `0.2.1+5`.
- Etonify использует модифицированное [ядро sing-box от dudosxdev](https://github.com/dudosxdev/sing-box).
